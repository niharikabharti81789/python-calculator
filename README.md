 python-calculator
This is a beginner-friendly Python Calculator project.

 Features
- Addition
- Subtraction
- Multiplication
- Division
- Continuous execution using loop
- Exit option available

 Technologies Used
- Python

 How to Run

```bash
python calculator.py
```
